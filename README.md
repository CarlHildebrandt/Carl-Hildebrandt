## 🚀 Building at Westfield

| Project | What it does |
| --- | --- |
| **[Pressure-Driven Memory](https://pypi.org/project/pdm-memory/)** | Persistent, resonance-based memory for AI programs. Selects relevant retained meaning for the current task and keeps outcomes available for later comparison. |
| **[AZUS](https://azus.ai)** | Connects persistent memory, contextual retrieval, ongoing review, and prediction-and-outcome feedback across interactions. |
| **[AZUS Field](https://field.azus.ai)** | Field operations for working crews: hours, receipts, work records, and handoffs, with a record that can be checked afterward. |
| **Industrial AI / PLC integration** | Architecture in which a model proposes, deterministic controls check authority and conditions, and the PLC retains its own permissives and interlocks. |
| **Boundary Lock & Westfield Witness** | Defined change boundaries and an observer that records the exchange without issuing the machine command. |

- **EE Curve Tool** examines interactions through loss, storage, timing, and the relationship between an input and its result.
- **The Grinder** carries ideas into committed predictions, compares them with outcomes, and records what held, what failed, and what changed.

The Noun Probe and EE Curve Tool are free to use, share, and adapt with their credit blocks attached.
